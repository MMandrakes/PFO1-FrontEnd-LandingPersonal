# PFO1 - Landing de Portafolio

## Descripción

Landing page de portafolio personal desarrollada con HTML5 y CSS3. Incluye presentación, habilidades técnicas, proyectos personales y formulario de contacto.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, variables CSS, animaciones)
- Google Fonts (Inter + Playfair Display)
- Accesibilidad (roles ARIA, etiquetas semánticas)

---

## Decisiones de diseño

### Estructura HTML

- Etiquetas semánticas: `header`, `nav`, `main`, `section`, `article`, `footer`
- Roles ARIA para accesibilidad (`banner`, `main`, `navigation`)
- Atributos `aria-label`, `aria-labelledby` y `aria-current`
- Comentarios en el código para organizar secciones

### Maquetación

- **Flexbox:** navegación, botones y footer
- **Grid:** tarjetas de habilidades y proyectos
- Diseño responsive con `clamp()`, `min()` y `auto-fit`

### Estilos

- Variables CSS para colores y transiciones
- Gradiente en título principal
- Línea decorativa en `h2`
- Contraste y legibilidad optimizados

### Interactividad

- Animación de galería de fotos con desvanecimiento
- Efectos hover en cards y botones
- Scroll suave
- Soporte para `prefers-reduced-motion`
